# 项目说明 (Project README)

## 概述
这是一个酒店管理学生实训系统，基于 Qt 6 (C++) 开发。系统包含三个主要测试模块：
1.  **Test 1: 业务学习 (幻灯片)** - 展示图片进行教学。
2.  **Test 2: 知识测验 (选择题)** - 19道选择题，支持点击图片预览，最后提交显示成绩。
3.  **Test 3: 模拟实训 (RPG)** - 模拟酒店布草配送流程，包含任务领取、物品拖拽、库存管理、突发事件处理等。

## 模块逻辑详解

### Test 1: 业务学习
*   **逻辑**: 依次展示 `:/source/Test1/` 下的图片。
*   **交互**: 点击“下一张”切换，最后一张点击完成后解锁下一关。

### Test 2: 知识测验
*   **逻辑**: 加载预设的 19 道题目。
*   **UI**: 左侧显示题目图片（可点击放大），右侧为 4 个选项卡片。
*   **结算**: 用户答完所有题目后点击“提交”，系统比对用户选择与正确答案，计算得分并显示详情列表。
*   **修改题目/答案**: 在 `test2.cpp` 的构造函数中修改 `quizData` 列表。`correctIndex` (0=A, 1=B, 2=C, 3=D)。

### Test 3: 模拟实训 (RPG)
*   **核心流程**: 打卡 -> 领取任务 -> 仓库取货 -> 电梯 -> 楼层布草间 -> 放置物品 -> (突发事件) -> 办公室汇报 -> 打卡下班。
*   **坐标与图片配置**:
    *   所有坐标配置位于 `test3.h` 的常量定义区域 (`COORD_*`, `SHELF_RECT_*`)。
    *   申领表上的文字位置需根据 `申领表.png` 的实际像素调整 `COORD_*`。
    *   货架物品点击区域需调整 `SHELF_RECT_*`。
    *   图片资源位于 `source/Test3/`，代码中使用 `:/source/Test3/` 前缀引用。
*   **任务生成规则**:
    *   随机生成 4~6 种布草需求。
    *   每种数量 1~10，符合正态分布（均值 5）。
*   **突发事件 (Emergency Events)**:
    *   可在“学生信息登记”页面右下角开启。
    *   **事件 A (加单)**: 额外增加一个楼层（2-12层）的任务单。
    *   **事件 B (脏布草)**: 目标楼层布草间出现“脏布草”。
    *   **规则**: 推车不能混装干净和脏布草。必须先清空推车（完成派送）才能回收脏布草。
*   **开发者模式**:
    *   在 `main.cpp` 中设置 `DEV_MODE_DEFAULT = true` 或在主菜单勾选。
    *   开启后，点击 RPG 场景会弹出当前鼠标坐标，方便校准位置。点击申领表也会显示坐标。

## 编译与运行
*   使用 CMake 构建。
*   确保 `source` 目录下的资源已正确生成 `resources.qrc` 并编译。
